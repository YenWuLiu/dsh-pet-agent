# 角色设定书：小蓝（桌宠「蓝鲸鱼女仆」）

> 来源：用户提供的两张表情包（吃干饭.png / 没吃饱.png）+ Kimi Work 产出的正式设定图
> （三视图 / 表情集 / 局部特写 / 色板 / 彩蛋姿势，存于 assets-custom/ref-src/）。
> 本文档是所有素材制作的**唯一事实来源**：AI 提示词从这里取，生成结果按这里验收。
> 改动形象 = 改本文档，不要只在某条提示词里偷偷改。

## 1. 一句话设定

主人桌面上蹭吃白饭的 Q 版蓝鲸鱼小女仆——圆滚滚、委屈巴巴但嘴硬，饿了会喵喵叫。

## 2. 体型与默认姿态

- **Q 版二头身**：头占全身约一半，圆脸、短身、小手小脚。
- **基准姿态**：
  - **站立**（Kimi 设定图三视图为站姿，移动类动画基准）；
  - **跪坐/鸭子坐**（表情包姿势，待机与静态事件可用）。
- **默认朝向**：面向画面**左侧**（引擎右镜像翻转，素材统一朝左）。
- **构图**：角色身高占画面高度 60~70%，居中偏左，四周留绿幕空间，脚（裙摆）贴画面底部。

| 部位 | 细节（锚点加粗） |

## 4. 可变量（允许随动作变化）

- 表情（眼型/嘴型/红晕深浅）
- 呆毛和鱼尾的摆动角度
- 裙摆/围裙的褶皱走向
- 动作需要的道具（钱袋、抹布、文件等，用完即走，不进锚点）

## 5. 绝不许变（验收红线）

1. 发色蓝系渐变（不许变绿/紫/黑）
2. 鱼鳍耳 + 鲸鱼尾巴必须都在（变成猫耳/翅膀 = 废片）
3. 女仆装三件套：发箍、黑领结、白围裙
4. 二头身比例（变五头身 = 废片）
5. 画面内只能有她一个角色，不许出现手/其他人

## 7. 生成结果验收清单（每条片子逐帧抽查）

- [ ] 第一眼：是她本人（对照第 3 节锚点表）
- [ ] 背景：全片绿色均匀无漂移（抽第 1 / 中 / 末帧）
- [ ] 构图：全程全身入镜、未出画、无镜头移动
- [ ] 动作：只做了要求的那个动作，无加戏
- [ ] 循环性（仅 idle）：首尾帧姿势一致
- [ ] 时长/帧数符合该动画要求（移动类检查首尾静止段）

## 9. 道具与特效（来自「道具与特效表.png」）

- **虎鲸饭碗三态**：满碗冒尖 / 吃了一半 / 舔干净——吃类动画与余额事件的道具原型；
  配套深蓝筷子（筷尾有鱼尾雕花）。
- **小鲸鱼伙伴**（喷水/睡觉/游泳/被抱）：扩充池「鲸鱼吐泡泡特效」「蓝鲸现世」的配角原型。
- **特效件**：鼻涕泡（大中小）、空气泡、水花、闪光、爱心、生气符、汗滴——
  AI 生成时通常自行补全，不必逐帧指定；验收时以这些样式为准。
- **互动道具**：窗口边缘（挂点）、白色手套光标、深蓝小窝垫——其中手套光标
  对应 assets/pic 的 cursor-grab/cursor-grabbing 图标原型，小窝垫可用于睡觉场景。
- **彩蛋姿势**（趴地抱饭碗）与「单发梗」（趴地吹大鼻涕泡）：扩充池彩蛋动作的原型。
