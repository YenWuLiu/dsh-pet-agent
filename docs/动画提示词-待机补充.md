# 待机动作提示词（补充 4 条）

> **用法**：这份是 `原始素材\prompts.json` 的**增量**，补 `idle` 池（现有 休闲待机 一条）。
> 每条的五个字段（`name` / `slot` / `first_frame` / `last_frame` / `prompt`）与现有 job 完全同构，
> 直接粘进 `jobs[]` 即可；同名文件也已生成好：
> [`动画提示词-待机补充.jobs.json`](动画提示词-待机补充.jobs.json)（数组，转义已处理）。
> 生成参数沿用现有：`fps 24`、`canvas 1024×576`、首末帧锚图 `正面锚点-1024x576.png`。
>
> **待机与其他篇的结构差异**：idle 是**链式重滚**的常驻动画（`playIdle` 播完再掷点，
> 滚回 idle 就原地 seek 回 0），所以它的契约最严：**首尾帧无缝一致**。四条的结构统一为
> "平静待机（呼吸 + 尾巴摇摆 + 偶尔眨眼）→ 一个小动作 → 收束回平静"，
> 中段动作幅度刻意做小、不偏离站姿 —— 它不是"反应"，是常驻动画的调味。
>
> **出片盯检点**：① **首末帧差分验收**（idle 硬契约，比 clicks 更严）——
> 衔接差应接近常规帧间差量级（参考 休闲待机 的实测口径：首尾接缝差 1.07 ≈ 帧间差 0.259 的 4.1 倍，
> 新片争取更小）；② 中段小动作幅度小、站姿不漂移；③ 不加戏、不带任何道具与特效。
>
> 槽位用 `idle`（与引擎待机池同名，不是生成批次桶 `小动作`）。运行时进 `idle` 池。
> 四条都不带文字、镜像后语义正常，**不需要** `noMirror`。
> 命名沿用 `待机-` 前缀，与已交付清单无冲突（已比对 `assets\config.jsonc`）。
>
> **出片进度（2026-09-24）**：已出片 1 条（整理仪容），待出 3 条（打哈欠 / 逗尾巴 / 伸懒腰）。
> `待机-整理仪容` 实测：锚点契约达标；**首尾接缝比值 3.4×**（接缝 9.90 / 帧间差 2.89），
> 比 `休闲待机` 的 4.0× 还好，而且接缝 **小于它自己最差的相邻帧差 12.78** —— 合格的无缝片。
> 口径见 [`动画设计与衔接规范.md`](动画设计与衔接规范.md) §8。后续三条出片后按同一把尺子量。

## 1. 待机-打哈欠

```prompt
【背景（最高优先级，全程不可违背）】
纯绿幕抠像背景：背景是一整块均匀、平面、无光照的 #00FF00 绿幕布。整面背景从第 0 帧到最后一帧亮度与色值完全恒定：没有任何灯光把背景打亮或压暗，没有渐变，没有阴影，没有投影，没有光斑，没有景深，没有任何装饰。画面中永远只有这一个角色站在纯绿幕布正前方，除此之外空无一物。纯绿幕布从角色身后一直铺到画面底边；角色站立、起跳、悬空的正下方始终是这块纯绿幕布，脚与幕布接触处颜色与四周完全一致。

【角色】
Q 版蓝发鲸鱼女仆，与首帧锚图完全一致：同一角色、同一服装、同一发型、同一画风、同一大小，角色受光均匀恒定。

【首末帧硬约束】
第 0 帧与末帧由外部锚图锁定，均为标准正面站立：双脚并拢、双手自然垂于身体两侧、表情平和、目光平视前方。
- 本条是待机动画：首尾帧无缝一致（idle 链式重滚，滚回时不得有跳变），中段动作幅度小、不偏离站姿。
- 角色不放大、不缩小、不平移，双脚落点始终固定在画面水平正中。
- 最后 1 秒内彻底回到标准站姿与干净纯绿画面。
- 第 1 秒之前完全静止。

【位置与安全区】
角色身高恒定为画幅高度的 75%，脚底距底边 8.3%，水平居中。全程任何部位（含呆毛、鳍耳、裙摆、鲸鱼尾巴、指尖）都在画幅内，与四边保持至少 8% 的纯绿间距。打哈欠与揉眼全程，身体保持在画幅安全区内，双脚落点不平移。

【构图与镜头】
固定机位，镜头完全不动，全身入镜。只表演下面描述的一个动作，不加戏。

【动作】
0~2.5秒（平静待机）：标准正面站立。保持轻柔的呼吸起伏，鲸鱼尾巴缓慢左右摇摆，偶尔眨眼，动作轻柔缓慢，有无缝循环感。
2.5~5秒（打哈欠）：她眼皮渐渐变沉，忍不住张大嘴打了一个大大的哈欠（头微微后仰、眼睛眯起，右手抬到嘴边轻轻挡了挡）。
5~7.5秒（擦眼角清醒）：打完哈欠，她眨了眨泛出泪花的眼睛，用指尖轻轻擦了擦眼角，又轻轻摇了摇头让自己清醒（呆毛随摇头轻晃），表情重新精神起来。
7.5~10秒（回归平静）：小动作完全收束，双手垂落至身体两侧，回到标准正面站立，只剩轻柔的呼吸起伏与尾巴缓慢摇摆。第 10 秒结束时彻底恢复为标准正面站立，与第 0 帧无缝一致。

【结尾重申】
全程纯绿背景 #00FF00，除角色本身外画面中不出现任何东西；末帧与第 0 帧完全一致、无缝衔接。
```
