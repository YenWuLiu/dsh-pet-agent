# 点击回应动作提示词（补充 4 条）

> **用法**：这份是 `原始素材\prompts.json` 的**增量**，补 `clicks` 池（现有
> 点击回应-害羞惊讶 / 点击回应-开心跃动 两条）。每条的五个字段
> （`name` / `slot` / `first_frame` / `last_frame` / `prompt`）与现有 job 完全同构，
> 直接粘进 `jobs[]` 即可；同名文件也已生成好：
> [`动画提示词-点击回应补充.jobs.json`](动画提示词-点击回应补充.jobs.json)（数组，转义已处理）。
> 生成参数沿用现有：`fps 24`、`canvas 1024×576`、首末帧锚图 `正面锚点-1024x576.png`。
>
> **与舞蹈/玩耍篇的结构差异**：点击回应的用户体感 = **反应要快**，所以反应动作前置到
> **1.5 秒起**（首帧硬约束只要求第 1 秒之前静止），1.5~8.5 秒完成"反应 → 延续 → 平复"，
> 最后 1 秒彻底回标准站姿 —— 衔接契约：`clicks` 末帧 ≈ 中立站姿，播完回 idle 才不生硬。
> 四条情绪互不重复（生气破功 / 委屈哭哭 / 痒痒求饶 / 比心回敬），
> 与已有的 害羞惊讶、开心跃动 也错开。
>
> **出片盯检点**：① 反应必须干脆、不加戏（出现剧本外动作就重刷）；
> ② 跺脚 / 扭动时双脚落点不得平移；③ 哭哭条的眼泪不做成"泪流满面"，
> 只是眼眶含泪 + 揉眼，避免面部表情崩坏。
>
> 槽位用 `clicks`（与引擎点击池同名，不是生成批次桶 `小动作`）。
> 运行时进 `clicks` 池。四条都不带文字、镜像后语义正常，**不需要** `noMirror`。
> 命名沿用 `点击回应-` 前缀，与已交付清单无冲突（已比对 `assets\config.jsonc`）。
>
> **出片进度（2026-09-24）**：已出片 1 条（生气跺脚），待出 3 条（委屈哭哭 / 痒痒求饶 / 比心回敬）。

> 与已有两条（害羞惊讶 9.26 / 开心跃动 9.63）同量级，播完回 idle 不生硬。

## 1. 点击回应-生气跺脚

```prompt
【背景（最高优先级，全程不可违背）】
纯绿幕抠像背景：背景是一整块均匀、平面、无光照的 #00FF00 绿幕布。整面背景从第 0 帧到最后一帧亮度与色值完全恒定：没有任何灯光把背景打亮或压暗，没有渐变，没有阴影，没有投影，没有光斑，没有景深，没有任何装饰。画面中永远只有这一个角色站在纯绿幕布正前方，除此之外空无一物。纯绿幕布从角色身后一直铺到画面底边；角色站立、起跳、悬空的正下方始终是这块纯绿幕布，脚与幕布接触处颜色与四周完全一致。

【角色】
Q 版蓝发鲸鱼女仆，与首帧锚图完全一致：同一角色、同一服装、同一发型、同一画风、同一大小，角色受光均匀恒定。

【首末帧硬约束】
第 0 帧与末帧由外部锚图锁定，均为标准正面站立：双脚并拢、双手自然垂于身体两侧、表情平和、目光平视前方。
- 角色不放大、不缩小、不平移，双脚落点始终固定在画面水平正中。
- 最后 1 秒内彻底回到标准站姿与干净纯绿画面。
- 第 1 秒之前完全静止。

【位置与安全区】
角色身高恒定为画幅高度的 75%，脚底距底边 8.3%，水平居中。全程任何部位（含呆毛、鳍耳、裙摆、鲸鱼尾巴、指尖）都在画幅内，与四边保持至少 8% 的纯绿间距。跺脚与扭头全程，双脚落点不平移，身体保持在画幅安全区内。

【构图与镜头】
固定机位，镜头完全不动，全身入镜。只表演下面描述的一个动作，不加戏。

【动作】
0~1.5秒：标准正面站立，完全静止。
1.5~3.5秒（被点得生气）：她突然鼓起腮帮子，眉头微微皱起，双手叉腰，右脚原地干脆地跺了两下（脚跟抬起再落下、双脚不离开起始点），一副"哼"的表情。
3.5~6.5秒（扭头装生气）：她把头扭向左侧约 30°，眼睛斜斜地瞥着镜头，腮帮还鼓着，双臂在胸前交叉抱起，身体随呼吸轻轻起伏，呆毛随扭头动作翘了翘，一副"我生气了、不理你了"的样子。
6.5~8.5秒（偷瞄破功）：她保持扭头姿势不动，用眼角偷偷瞄了瞄镜头，嘴角忍不住翘了一下，终于绷不住噗地笑了，鼓着的腮帮泄了气，双臂放下，不好意思地挠了挠脸颊。
8.5~10秒（恢复）：笑容渐渐收拢，双手垂落至身体两侧，头部回正，完成一次深呼吸（胸口微起伏），表情恢复温和宁静。第 10 秒结束时彻底恢复为标准正面站立。

【结尾重申】
全程纯绿背景 #00FF00，除角色本身外画面中不出现任何东西；末帧与第 0 帧完全一致。
```
