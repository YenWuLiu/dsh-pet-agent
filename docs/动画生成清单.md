## 动作段（接在形象段后面，整段复制）

**待机（idle）** — 首尾帧要一致，循环才不跳：
```
她保持站姿原地轻轻呼吸起伏，鲸鱼尾巴缓慢左右摇摆，偶尔眨眼，动作轻柔缓慢，无缝循环感。
```

**转向（turn）** — 末帧要等于首帧的左右镜像：
```
她好奇地慢慢转头向左看、再向右看，然后原地转向使身体朝向相反一侧，结束时面向另一侧，全程面向镜头，不要背对镜头，结束姿势与开头左右镜像对称。
```

**拖拽（drag）** — 全程悬空：
```
她被无形之手拎着后领提离地面悬空，双脚离地，四肢自然下垂轻轻晃荡，表情无奈。
```

**移动（move）** — 首尾各留约 1 秒站立不动（引擎靠 `leadSec`/`tailSec` 在窗口内平移精灵）：
```
开头约1秒站立不动，然后原地慢悠悠走路踏步，裙摆和鲸鱼尾巴随步伐轻摆，结尾1秒站立不动回到站姿。
```

**点击回应（clicks）** — 末帧 ≈ 中立站姿：
```
她开心地摇起鲸鱼尾巴，眼睛亮闪闪，轻轻跳一下，然后回到中立站姿。
```
```
她鼓起腮帮子假装生气，原地跺两下脚，哼一声把头扭向一边，然后回到中立站姿。
```
```
她被吓到后仰跌倒坐地，愣一下，然后爬起身回到中立站姿，不要烟雾灰尘特效。
```

**小动作** — 末帧 ≈ 中立站姿：
```
她原地坐下，双手抱住膝盖，下巴搁在膝上发呆，鲸鱼尾巴在身侧轻轻摆动，然后慢慢站起来回到站姿。
```
```
她趴到地上闭眼熟睡，鼻尖鼻涕泡一大一小地起伏，鲸鱼尾巴偶尔轻摆，然后醒来爬起身回到站姿。
```
```
她跪坐着端起饭碗拿筷子开心地扒饭吃，腮帮子鼓鼓地咀嚼，饭碗端在手里，然后放下碗站起身回到站姿。
```
```
她走向画面右侧边缘，双手攀住画幅右边缘悬挂起来，双脚离地，双腿悬空晃动，鲸鱼尾巴摇摆，然后松手跳下回到站姿。
```
```
她原地起跳，双手攀住画幅顶部边缘悬挂，身体下垂晃动，双腿晃荡，鲸鱼尾巴摇摆，然后松手落地回到站姿。
```

## 两条硬性衔接规则

- **除 idle / turn 外，所有单次动画的末帧都要回到「中立站姿」** —— 播完回 idle 才不生硬。
- **turn 的末帧必须等于首帧的左右镜像** —— 引擎播完只负责翻 `facing`，转向得由动画自己完成。
