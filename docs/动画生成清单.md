## 4. 12 条完整提示词（形象段 + 画面段 + 动作段，可直接整段粘贴）

> 以下每条 = 第 3 节模板（形象段 + 画面段）+ 本动作的动作段。生成时直接整段复制。

### ① 待机呼吸休闲（idle）
```
{第3节模板}。她保持站姿原地轻轻呼吸起伏，鲸鱼尾巴缓慢左右摇摆，偶尔眨眼，动作轻柔缓慢，无缝循环感。
```

### ② 东张西望（turn）
```
{第3节模板}。她好奇地慢慢转头向左看、再向右看，然后原地转向使身体朝向相反一侧，结束时面向另一侧，全程面向镜头，不要背对镜头，结束姿势与开头左右镜像对称。
```

### ③ 被鼠标拖拽悬空反馈（drag）
```
{第3节模板}。她被无形之手拎着后领提离地面悬空，双脚离地，四肢自然下垂轻轻晃荡，表情无奈。
```

### ④ 悠闲散步（move）
```
{第3节模板}。开头约1秒站立不动，然后原地慢悠悠走路踏步，裙摆和鲸鱼尾巴随步伐轻摆，结尾1秒站立不动回到站姿。
```

### ⑤ 点击回应-开心摇尾（clicks）
```
{第3节模板}。她开心地摇起鲸鱼尾巴，眼睛亮闪闪，轻轻跳一下，然后回到中立站姿。
```

### ⑥ 点击回应-生气跺脚（clicks）
```
{第3节模板}。她鼓起腮帮子假装生气，原地跺两下脚，哼一声把头扭向一边，然后回到中立站姿。
```

### ⑦ 点击回应-惊吓跌倒（clicks）
```
{第3节模板}。她被吓到后仰跌倒坐地，愣一下，然后爬起身回到中立站姿，不要烟雾灰尘特效。
```

### ⑧ 坐姿抱膝（小动作池）
```
{第3节模板}。她原地坐下，双手抱住膝盖，下巴搁在膝上发呆，鲸鱼尾巴在身侧轻轻摆动，然后慢慢站起来回到站姿。
```

### ⑨ 趴地熟睡（小动作池）
```
{第3节模板}。她趴到地上闭眼熟睡，鼻尖鼻涕泡一大一小地起伏，鲸鱼尾巴偶尔轻摆，然后醒来爬起身回到站姿。
```

### ⑩ 跪坐干饭（小动作池）
```
{第3节模板}。她跪坐着端起饭碗拿筷子开心地扒饭吃，腮帮子鼓鼓地咀嚼，饭碗端在手里，然后放下碗站起身回到站姿。
```

### ⑪ 挂右边缘（小动作池）
```
{第3节模板}。她走向画面右侧边缘，双手攀住画幅右边缘悬挂起来，双脚离地，双腿悬空晃动，鲸鱼尾巴摇摆，然后松手跳下回到站姿。
```

### ⑫ 挂顶边（小动作池）
```
{第3节模板}。她原地起跳，双手攀住画幅顶部边缘悬挂，身体下垂晃动，双腿晃荡，鲸鱼尾巴摇摆，然后松手落地回到站姿。
```

## 5. 即梦生成操作（每条）

1. 打开即梦网页版 → AI 视频 → 图生视频（Seedance 2.0）；
2. 上传**首帧** = 第 2 表对应 `refs-redesign/姿势-NN.png`；
3. 上传**参考图** = `ref-src/三视图与表情.png`（角色一致性，每条都同一张）；
4. 粘贴第 4 节对应完整提示词；
5. 参数：**5 秒 / 3:4 / 固定机位 / 白底**（运动强度：动作大的如小跑/转圈选高，静态如抱膝/熟睡选低）；
6. 生成 → 预览满意 → 下载 mp4，命名为 `<动画名>.mp4`，存入 `assets-custom/raw-staging/`；
7. 一条不满意就在即梦重出几次再下载（比转码后返工便宜）。

## 6. 收片与转码（批量）

```powershell
# ① 首选：人工抠好的透明母版（剪映等，720×1280 原分辨率、无水印）→ 只做几何归一化
python scripts\normalize-webm.py <母版目录> assets\webm --anchor <idle动画名>
# ② 兜底（没有人工母版时）：自动抠像
#    全部 mp4 放进 raw-staging/ 后：
.\scripts\convert-jimeng-batch.ps1      # key-video → 640×360 透明 webm（自带锚点契约）
.\scripts\check-assets.ps1              # 规格验收（分辨率/alpha/引用对齐 + 锚点契约）
```
素材全部到位后：用 `assets-custom/config-redesign.jsonc` 覆盖 `assets/config.jsonc`，重启生效。

**素材优先级（2026-09-14 实测结论）**：人工抠（剪映手工精修边缘）> 自动抠像。
自动抠（key-video.py 洪水填充 / mp4-keyer 色度键）能过验收线，但边缘质感与接缝都略逊
（实测：手动母版归一化后接缝 3.8~6.1，自动重抠 4.7~7.7）。**有母版就别再自动抠一遍**——
`normalize-webm.py` 只改几何（裁剪/缩放/补透明边），会原样保留人工 alpha。

**锚点契约（每片必须满足，2026-09-14 起为 key-video.py 默认值 `--anchor frame0`）**：
角色高 = `target_h×360`（默认 270px）、脚底线 = `FEET_Y=330`、水平中心 = `x=320`
（常量见 `runtime/electron-helper/shared-core.js`）。**必须按"首帧站姿"缩放，不能按整片
union 缩放**——否则跳跃/抬手的大动作片会被整体压小，出现"待机正常、一点击就变小悬空"。
另外即梦出片带"AI生成"水印（与角色是两个独立不透明块），量角色一律**只取最大连通块**，
否则量到的是"头顶→水印底"。验收用 `scripts/check-anchor.py`（已并进 check-assets.ps1）：
逐片比对首帧角色高 / 脚底线 / 水平中心，与 idle 锚点偏差 >8px 即报错。

## 7. 验收要点（对照 CHARACTER.md §7，重点四项）

1. **是她本人 + 风格统一**：抽首帧对照 `三视图与表情.png`（同一画风）；
2. **尾巴全程清晰可见**：弯在身侧、不消失、不被完全遮挡（逐帧抽查）；
3. **衔接**：单次动画末帧 ≈ 中立站姿；idle 首尾帧一致；turn 末帧镜像；move 首尾站立段。
4. **锚点契约**：`python scripts/check-anchor.py` 全绿（各片首帧角色高/脚底线/中心与 idle 一致，
   且全片动作幅度不出 640×360 画布、无水印残留小块）；另外抽帧叠在 idle 首帧上看观感是否同尺寸。
5. **循环与接入（2026-09-14 起）**：
   - idle 必须是**无缝循环段**，不是整片：`python tools/find-loop.py <idle片>` 找接缝；
     判据是接缝 RMS ≤ 该片自身常规帧间差（整片硬接通常是它的 3 倍以上）。
   - 动作片必须用 `python scripts/build-chain.py` 烘焙成 **待机+主体+待机** 再上线：
     验收看首帧 == idle 首帧、末帧 == idle 末帧前一帧（RMS ≈ 0，只剩一次编码代差），
     以及内部两段溶解的逐帧步进不超过局部运动基底。`assets-custom/raw-local/chain-report.json`
     会记下每条片的实测值。
