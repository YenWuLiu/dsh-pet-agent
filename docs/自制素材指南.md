# 自制素材指南：从零换掉整套桌宠素材

本项目桌宠的全部视觉素材 = **webm 动画 + ttf 字体 + png 图标**三类，
都经 HTTP 端点按名取用。本文档是「从零自制」的完整指引。

**当前定稿方案**（2026-09 版）：角色 = 蓝鲸鱼小女仆「小蓝」（设定见
`assets-custom/CHARACTER.md`），动画 = 动作姿势表 **12 种**（I2V 图生视频，
逐条姿势图锚定首帧），绿幕法抠像，旧内置素材全作废。

相关文件：

| 内容 | 位置 |
|---|---|
| 角色设定书（唯一事实来源） | `assets-custom/CHARACTER.md` |
| 待产清单（12 动画 + 1 字体 + 8 图标） | `assets-custom/CHECKLIST.md` |

## 1. 素材系统工作原理（理解后再动手）

**动画**：`assets/config.jsonc` 的 `animations` 段按名字引用动画，
渲染端把名字拼成 URL 取文件（`runtime/electron-helper/renderer.js:405`）：

```
配置里写 "待机呼吸休闲"  →  GET /dsh-pet-7340/thumb/main/待机呼吸休闲.webm
```

查找顺序（`src/server.ts:550-553`）：先看用户目录
`~/.dsh/dsh-pet/main-animation/webm/`，没有再看内置 `assets/webm/`。
**制作期把转好的 webm 丢进用户目录就能立刻预览**，内置素材兜底，宠物不会瘫。

**字体**：气泡字体文件名被硬编码为 `上首软糖体.ttf`
（`runtime/electron-helper/renderer.js:1750-1754`）。换字体 = 用同名文件覆盖
（swap 脚本会自动改名），想改文件名就得改这处代码。

**图标**：6 个通知图标名硬编码在 `runtime/electron-helper/shared-core.js:376-383`，
2 个光标名硬编码在 `renderer.js:1755-1760`。同理：同名覆盖最省事。

**播放契约**（渲染端行为，制作时必须遵守）：

| 规则 | 出处 | 对制作的要求 |
|---|---|---|
| 只有 idle 循环播放，其余全部单次播放 | `renderer.js:406` | `待机呼吸休闲` 首尾帧必须无缝衔接 |
| 单次播放动画播完回 idle | `renderer.js:473-479` | 所有单次动画**结束姿势 = 起始姿势**（连贯性总则） |
| 角色默认面向左，朝右时 CSS 镜像 | `renderer.js:424` | 素材统一朝左；带文字的动作归到 `noMirror` 分类 |
| turn 动画播完时引擎翻转朝向 | `renderer.js:482-483` | `东张西望` 结尾朝向必须与开头相反 |
| 移动动画首尾各有一段「原地不动」 | 配置 `leadSec/tailSec` | `悠闲散步` 首尾各 2 秒站立段 |
| 事件动画按数组索引分档 | `config.jsonc` events 注释 | 当前 12 动画制下事件池为占位+功能关闭 |

## 2. 素材规格

- **动画**：webm 容器，VP9 + Alpha（yuva420p），**640×360**（16:9），无音轨。
  宠物显示高度 = 宽度 × 9/16，角色在画幅内的占比直接决定视觉大小。
- **字体**：ttf（服务端也认 woff/woff2，见 `src/server.ts:70-72`）。
  本项目用 **站酷快乐体 2016**（站酷字体免费可商用），npmmirror 渠道
  `@fontpkg/happy-zcool-2016` 可直接拿到完整 ttf。
- **光标**：透明 PNG，48×48，热点 (16,16)；本项目用设定图手套指针裁抠。
- **通知图标**：透明 PNG，256×256；本项目用表情集裁抠（映射见 `scripts/make-icons.py`）。

## 3. 制作工作流（本地 I2V 图生视频）

```
① 角色设定图（Kimi Work 出）→ ref-src/；make-pose-refs.py 裁抠出 12 张绿幕姿势图
        ↓
② .\scripts\gen-videos.ps1 -I2V -TimeoutMin 60        # 逐条姿势锚定，批量出片进 raw/
        ↓  （单条约 15~25 分钟：14B fp8 + 8GB 显存权重卸载，适合挂过夜）
③ .\scripts\convert-assets.ps1                       # 自动取样背景色 → 抠绿 → 640×360 透明 webm
        ↓
④ 质检（见 CHARACTER.md 第 7 节清单；废片删 raw 重生成）
        ↓  .\scripts\check-assets.ps1
⑤ .\scripts\swap-assets.ps1 → 重启 pnpm start
```

前置依赖：**ffmpeg ≥ 7**（已内置 `tools\ffmpeg.exe`）；ComfyUI 本地实例
（Wan 2.1 I2V 14B fp8 + umt5_xxl_fp8 + wan_2.1_vae + clip_vision_h）。

**I2V 实测配方**（踩坑记录）：
- 参考图绿幕**不要用纯 #00FF00**（VAE 训练分布外，重建出噪点+漂移）——
  用自然绿 #35B558 并加 ±2 全图噪点（make-ref.py 已内置）；
- KSampler：**cfg 6.0 / steps 25 / uni_pc / simple / shift 8.0**（cfg 降到 5 会第 2 帧就发散，实测）；
- 帧数 49~81（3~5 秒），越长漂移风险越大。

**抠像参数**：默认 `-KeyColor auto`（逐文件取首帧角点实际背景色）。
实测 Similarity 0.15 / Blend 0.05 干净；0.30 会把白围裙抠穿。

## 4. 换血之后

- `swap-assets.ps1` 把内置素材整体移到仓库外的 `..\assets-backup-<时间戳>\`
  （不删数据，确认无误后可自行删备份），并把 `assets/config.jsonc`
  换成 12 动画版。余额/碎碎念/工作状态三功能随配置关闭（事件池占位）。
- 内置素材的「禁止商用」限制随删除一并解除；代码仍按 MIT。
- `assets/` 是 git 跟踪的，换血会体现为一次大批量删除+新增，单独提交即可。

## 5. 后续扩充动作库（新动作集来了之后）

1. 把新姿势图放进 `assets-custom/ref-src/`，按 `make-pose-refs.py` 的方式裁抠成绿幕姿势图；
2. 在 `gen-videos.ps1` 的 `$actions` 加「动画名 → 动作描述」、在 `$poseMap` 加锚点映射，
   跑 `.\scripts\gen-videos.ps1 -I2V -Only <动画名>` 单条生成；
3. `convert-assets.ps1` 抠像后进 `assets/webm/`（swap 后）或 `assets-custom/webm/`（swap 前）；
4. 在 `assets/config.jsonc` 加名字（`categories` 追加分类/动作，
   **保持权重守恒**：animationWeights 三项 + 各分类 weight = 100）；
5. 刷新/重启生效，无需改代码。

## 6. 常见问题

- **宠物显示「配置加载失败」**：config.jsonc 写错了（JSONC 语法/缺必填段），看终端告警。
- **右键菜单点了动作没反应/报错**：该名字没有对应 webm（404），
  跑一遍 `.\scripts\check-assets.ps1 -Config assets\config.jsonc -WebmDir assets\webm` 对齐。
- **动画播完卡住**：webm 损坏或编码不带 alpha 导致解码失败，用 check-assets 复核。
- **角色在画面里偏小/偏大**：生成时调整角色占比；或改宠物的 `size`（宽度 px）。
- **I2V 第二帧起画面崩坏成迷幻色块**：cfg 太低（≥6）或绿幕太纯（用 #35B558 + 噪点）。
