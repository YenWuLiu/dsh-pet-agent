# 玩耍动作提示词（补充 5 条）

> **用法**：这份是 `原始素材\prompts.json` 的**增量**，与待出片的「踢毽子」「抽陀螺」
> 同系列的新增原地玩耍变体。每条的五个字段（`name` / `slot` / `first_frame` / `last_frame` / `prompt`）
> 与现有 job 完全同构，直接粘进 `jobs[]` 即可；同名文件也已生成好：
> [`动画提示词-玩耍补充.jobs.json`](动画提示词-玩耍补充.jobs.json)（数组，转义已处理）。
> 生成参数沿用现有：`fps 24`、`canvas 1024×576`、首末帧锚图 `正面锚点-1024x576.png`。
>
> **模板**：固定五段沿用 v3 绿幕规范（与踢毽子/抽陀螺两条逐字同构），因动作里有
> "道具凭空凝聚 → 消散"，`【背景】`、`【首末帧硬约束】`、`【结尾重申】` 各含道具例外句 ——
> 与折扇、手持镜、乐器是同一处理思路。五条覆盖投掷 / 吹转 / 搓飞 / 拍弹 / 腰摇五类玩法，
> 动作互不重复，且避开了已有条目（吹气球、三球抛接、扑克魔术、蝴蝶蜜蜂环绕头顶开花）。
>
> **出片三个盯检点**：① 飞行 / 弹跳道具（纸飞机、竹蜻蜓、皮球）是与角色不连通的元素 ——
> 归一化的"全部内容 bbox 裁剪窗"支持它们，但飞行轨迹不可控，盯是否飞出画 / 挡脸；
> ② 呼啦圈绕腰与裙摆、鲸鱼尾巴交叉，是穿模高发 —— 圈被裙摆"吃掉"或圈身断裂就重刷；
> ③ 凭空变道具若翻车，降级句式同乐器篇："凭空变出"→"从身后取出"、"凭空消散"→"递回身后"。
>
> 槽位沿用生成批次桶约定，统一 `小动作`；运行时建议进「玩耍」分类
> （与踢毽子 / 抽陀螺 / 舞蹈 / 乐器同池，见 `assets\config.jsonc` 的分池口径注释）。
> 五条都不带文字、镜像后语义正常，**不需要** `noMirror`。
> 命名与已交付清单无冲突（已比对 `assets\config.jsonc` 的 52 条）。

## 1. 掷纸飞机

```prompt
【背景（最高优先级，全程不可违背）】

【角色】
Q 版蓝发鲸鱼女仆，与首帧锚图完全一致：同一角色、同一服装、同一发型、同一画风、同一大小，角色受光均匀恒定。

【首末帧硬约束】
第 0 帧与末帧由外部锚图锁定，均为标准正面站立：双脚并拢、双手自然垂于身体两侧、表情平和、目光平视前方，画面中无纸飞机。
- 角色不放大、不缩小、不平移，双脚落点始终固定在画面水平正中。
- 纸飞机由角色身前凭空凝聚出现，结束前完全消散，末帧无任何残留。
- 最后 1 秒内彻底回到标准站姿与干净纯绿画面，白色光点完全消失。
- 第 1 秒之前完全静止。

【位置与安全区】
角色身高恒定为画幅高度的 75%，脚底距底边 8.3%，水平居中。全程任何部位（含呆毛、鳍耳、裙摆、鲸鱼尾巴、指尖）都在画幅内，与四边保持至少 8% 的纯绿间距。纸飞机的飞行与滑翔轨迹全程在画幅安全区内、不遮挡面部，最高点不超过画幅上部安全区。

【构图与镜头】
固定机位，镜头完全不动，全身入镜。只表演下面描述的一个动作，不加戏。

【动作】
Q 版蓝发女仆在纯绿幕前原地玩纸飞机，双脚起始点不偏移（可原地踮脚、探身）：
0~2秒（变出纸飞机）：第 1 秒前保持标准正面站立、完全静止、手中无物；随后双手从身前以魔术般的动作凭空变出一架 Q 版纸飞机（洁白的折纸飞机，折痕清晰、机翼圆润），捧在掌心翻看，随后把机头凑到嘴边轻轻哈了一口气（像起飞前的小仪式），表情期待。
2~4秒（试掷）：右手把纸飞机举到肩旁，身体微微后仰，向前轻轻一掷——纸飞机向前滑出一小段平缓弧线，在身前约一个身位处滑翔片刻，随后拐个小弯轻轻飞回面前；她伸出右手稳稳接住，眼睛一亮，嘴角一翘。掷出与接回全程双脚原地不动。
4~6.5秒（正式放飞）：她再次把纸飞机凑到嘴边哈一口气，右手高举向前上方掷出——这次纸飞机向上爬升（最高点不超过画幅上部安全区），在空中绕了一个小小的圆圈；她仰起头追看，头部随飞机小幅转动，右手搭在额前遮阳张望，表情兴奋。
6.5~8.5秒（滑翔接回）：纸飞机绕完圈开始滑翔下降，缓缓减速、像悬停般飘到她胸前；她伸出双手掌心向上，把纸飞机轻轻接住，低头看着掌心的飞机，满意地微笑，用指尖把机翼轻轻抚平。全程双脚原地不动。
8.5~10秒（消散 + 恢复正姿）：双手把纸飞机在胸前轻轻一托——纸飞机以魔术般的动作凭空消散（化作几片细小的白色光点飘散、随即散尽）。双手自然垂落，头部摆正，目光平视前方，嘴角带着一丝余兴未消的浅笑。第 10 秒结束时彻底恢复为标准正面站立。

【结尾重申】
全程纯绿背景 #00FF00，除角色与 Q 版纸飞机外画面中不出现任何东西；末帧与第 0 帧完全一致，无纸飞机、无光点残留。
```
