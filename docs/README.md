## 素材生产全链路

这是本项目最独特、也最容易踩坑的一条链，单独画出来：

```
docs/动画生成清单.md            提示词模板（形象段 + 动作段 + 两条硬性衔接规则）
        │
        │  复制进即梦 / 可灵等，逐条生成
        ▼
   绿幕 mp4 / 白底视频
        │
        │  手工抠像（关键：导出必须带 alpha —— qtrle / ProRes 4444 / PNG 序列）
        │  ⚠ 绝不要对已抠好的 matte 再跑一次 colorkey，会把 alpha 整个丢掉
        ▼
素材加工/input/*.mov           文件名 = 动画名，这一步就定死
        │
        │  双击 素材加工\出片.bat
        │    = python scripts/normalize-webm.py input ../DSH-PET-AGENT/assets/webm
        │      → 按最大连通块量角色高 → 缩到 270px → 首帧脚底对齐 y=330、中心对齐 x=320
        │      → 裁切窗含独立气泡/道具 → VP9-Alpha 640×360
        ▼
assets/webm/*.webm
        │
        │  把动画名挂进 assets/config.jsonc 的池子（idle / turn / clicks / moves / categories / events）
        │  ⚠ 忘了挂 = 静默失效，引擎永远不播（出片.bat 的第 3 步会反查并点名）
        ▼
.\scripts\check-assets.ps1     三项验收：齐备 + 640×360/真 alpha + 锚点契约
        │
        ▼
   pnpm start
```

配套的规格细节（画布、朝向、权重守恒、空池子语义、镜像规则）全在
[`动画设计与衔接规范.md`](动画设计与衔接规范.md) 与 [`../assets/README.md`](../assets/README.md)。

## 维护约定

- **一篇文档只讲一件事。** 提示词模板不放引擎契约，引擎契约不放提示词 —— 混在一起会两边都难查。
- **改了行为就改文档，同一个提交里改。** 本项目已经吃过"文档描述的工具根本不存在"的亏（见 `../tools/README.md` 的历史）。
- **路径写相对仓库根的写法**（如 `素材加工\出片.bat`），不写死本机绝对路径。
