## 1. 折扇舞

```prompt
【背景（最高优先级，全程不可违背）】
纯绿幕抠像背景：背景是一整块均匀、平面、无光照的 #00FF00 绿幕布。整面背景从第 0 帧到最后一帧亮度与色值完全恒定：没有任何灯光把背景打亮或压暗，没有渐变，没有阴影，没有投影，没有光斑，没有景深，没有任何装饰。画面中永远只有这一个角色站在纯绿幕布正前方，除此之外空无一物。纯绿幕布从角色身后一直铺到画面底边；角色站立、起跳、悬空的正下方始终是这块纯绿幕布，脚与幕布接触处颜色与四周完全一致。本条唯一例外：动作过程中角色手持一把素白折扇，折扇视作角色身上的道具，不算背景杂物；除角色与折扇之外，画面中依然空无一物。

【角色】
Q 版蓝发鲸鱼女仆，与首帧锚图完全一致：同一角色、同一服装、同一发型、同一画风、同一大小，角色受光均匀恒定。

【首末帧硬约束】
第 0 帧与末帧由外部锚图锁定，均为标准正面站立：双脚并拢、双手自然垂于身体两侧、表情平和、目光平视前方。
- 角色不放大、不缩小、不平移，双脚落点始终固定在画面水平正中。
- 最后 1 秒内彻底回到标准站姿与干净纯绿画面。
- 第 1 秒之前完全静止。

【位置与安全区】
角色身高恒定为画幅高度的 75%，脚底距底边 8.3%，水平居中。全程任何部位（含呆毛、鳍耳、裙摆、鲸鱼尾巴、指尖）都在画幅内，与四边保持至少 8% 的纯绿间距。开扇、挽扇花与转体全程，扇面边缘、指尖与裙摆始终保持在画幅安全区内，扇子不得超出画幅。

【构图与镜头】
固定机位，镜头完全不动，全身入镜。只表演下面描述的一个动作，不加戏。

【动作】
0~3秒（取扇与开扇）：标准正面站立。随后右手伸向身后，取出一把素白折扇（扇面无字无图案、无流苏），双手在胸前把扇缓缓展开至半开。左手轻搭右手腕，身体向右侧微倾约 5°，下巴轻抬，目光柔和含笑。
3~6秒（挽扇花与点地步）：右手腕带扇在胸前与身体右侧画小圆（扇花），左手随节奏在身侧提起再落下。双脚交替以脚尖轻点纯绿幕布（右脚尖点出后收回，随后左脚尖点出后收回，脚尖不离幕布，仅擦幕布画出弧线）。身体随扇花左右轻摆各约 5°，裙摆随摆动微微起伏，表情愉悦。
6~8秒（转体回眸）：折扇收到胸前竖直持握，身体以双脚为轴原地平滑转到微侧身（约 60°）再匀速转回正面；转体时左臂自身侧向外划出一道圆弧，扇面随手腕外翻一次。鲸鱼尾巴随转体向同一侧甩动，呆毛随之轻晃，表情从愉悦转为明亮的惊喜。
8~10秒（收扇与站姿收势）：双手在胸前把折扇合拢，右手将扇子递回身后腰间并松开（双手回到身侧后不再持扇、手里不留任何东西），双臂缓缓落至身侧，脚尖并拢，完成一次深呼吸（胸口微起伏），表情从惊喜恢复为温和宁静。第10秒结束时双手已空，彻底恢复为标准正面站立。

【结尾重申】
全程纯绿背景 #00FF00，除角色本身与本条所述折扇外，画面中不出现任何东西；末帧双手已空，与第 0 帧完全一致。
```
