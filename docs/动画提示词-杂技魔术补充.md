# 杂技魔术动作提示词（补充 4 条）

> **用法**：这份是 `原始素材\prompts.json` 的**增量**，与已交付的「扑克魔术」「三球抛接」
> 同系列的新增杂技/魔术变体。每条的五个字段（`name` / `slot` / `first_frame` / `last_frame` / `prompt`）
> 与现有 job 完全同构，直接粘进 `jobs[]` 即可；同名文件也已生成好：
> [`动画提示词-杂技魔术补充.jobs.json`](动画提示词-杂技魔术补充.jobs.json)（数组，转义已处理）。
> 生成参数沿用现有：`fps 24`、`canvas 1024×576`、首末帧锚图 `正面锚点-1024x576.png`。
>
> **模板**：固定五段沿用 v3 绿幕规范（与扑克魔术/三球抛接两条逐字同构），因动作里有
> "道具凭空凝聚 → 消散"，`【背景】`、`【首末帧硬约束】`、`【结尾重申】` 各含道具例外句 ——
> 与乐器篇、玩耍篇同一处理思路。四条覆盖挥舞 / 平衡 / 流动 / 帽中变物四类魔术杂技手法，
> 动作互不重复，且避开了已有条目（扑克悬浮、三球抛接）。
>
> **出片三个盯检点**：① 顶杆转盘与水晶球悬浮属"反重力"表演，模型容易做成道具掉落
> 或穿模 —— 翻车了删掉悬浮/顶转句，降级为"手持转动/双手滚球"重刷；
> ② 帽中变物是"遮挡中换物"，模型通常擅长，盯小鲸鱼玩偶是否画崩（物种特征：呆毛、尾鳍分叉）；
> ③ 凭空变道具若翻车，降级句式同乐器篇："凭空变出"→"从身后取出"、"凭空消散"→"递回身后"。
>
> 槽位统一 `小动作`（生成批次桶）；运行时建议进「玩耍」分类（与扑克魔术、三球抛接同池，
> 见 `assets\config.jsonc` 的分池口径注释）。四条都不带文字、镜像后语义正常，
> **不需要** `noMirror`。命名与已交付清单无冲突（已比对 `assets\config.jsonc` 的 52 条）。

## 1. 丝巾变色

```prompt
【背景（最高优先级，全程不可违背）】
纯绿幕抠像背景：背景是一整块均匀、平面、无光照的 #00FF00 绿幕布。整面背景从第 0 帧到最后一帧亮度与色值完全恒定：没有任何灯光把背景打亮或压暗，没有渐变，没有阴影，没有投影，没有光斑，没有景深，没有任何装饰。画面中永远只有这一个角色站在纯绿幕布正前方；本动作唯一允许的额外元素是一条Q版丝巾，此外空无一物。纯绿幕布从角色身后一直铺到画面底边；角色站立、起跳、悬空的正下方始终是这块纯绿幕布，脚与幕布接触处颜色与四周完全一致。

【角色】
Q 版蓝发鲸鱼女仆，与首帧锚图完全一致：同一角色、同一服装、同一发型、同一画风、同一大小，角色受光均匀恒定。

【首末帧硬约束】
第 0 帧与末帧由外部锚图锁定，均为标准正面站立：双脚并拢、双手自然垂于身体两侧、表情平和、目光平视前方，画面中无丝巾。
- 角色不放大、不缩小、不平移，双脚落点始终固定在画面水平正中。
- 丝巾由角色身前凭空凝聚出现，结束前完全消散，末帧无任何残留。
- 最后 1 秒内彻底回到标准站姿与干净纯绿画面，彩色光丝完全消失。
- 第 1 秒之前完全静止。

【位置与安全区】
角色身高恒定为画幅高度的 75%，脚底距底边 8.3%，水平居中。全程任何部位（含呆毛、鳍耳、裙摆、鲸鱼尾巴、指尖）都在画幅内，与四边保持至少 8% 的纯绿间距。丝巾挥舞全程在画幅安全区内飘动，不遮挡面部。

【构图与镜头】
固定机位，镜头完全不动，全身入镜。只表演下面描述的一个动作，不加戏。

【动作】
0~2秒（变出丝巾）：标准正面站立。双手从身前以魔术般的动作凭空变出一条Q版丝巾（洁白的方巾，四角圆润），双手捏着两角向镜头展示（正反面各亮一下），表情自信带笑。
2~4秒（抖巾变色）：双手各捏住丝巾一角，把丝巾轻轻一抖——丝巾像被魔法点亮，颜色从洁白平滑过渡为彩虹渐变色；她睁大眼睛看着变色的丝巾，嘴角上扬，又轻轻抖了一下让颜色更鲜艳。
4~6.5秒（挥舞飘扬）：右手捏着丝巾一角，在身前画着大大的圆挥舞（丝巾在空中飘出柔和的弧线，像在跳舞）；左手随节奏在身侧轻摆，身体随挥舞轻轻左右摇摆约 5°，头部跟随丝巾小幅转动，呆毛随摆动轻晃，表情陶醉愉快。丝巾全程在胸前与体侧安全区内飘动。
6.5~8.5秒（绕颈与变回）：挥舞放缓，她双手把丝巾轻轻绕到颈后、像戴围巾一样在胸前交叉，低头欣赏；随后双手捏住丝巾再一抖——颜色从彩虹渐变平滑变回洁白。她满意地笑了，把丝巾从颈上取下拢在双手间。
8.5~10秒（消散 + 恢复正姿）：双手把丝巾在胸前轻轻一拢——丝巾以魔术般的动作凭空消散（化作几缕彩色细光丝飘散、随即散尽）。双手自然垂落，头部摆正，目光平视前方，表情恢复温和宁静。第 10 秒结束时彻底恢复为标准正面站立。

【结尾重申】
全程纯绿背景 #00FF00，除角色与一条Q版丝巾外画面中不出现任何东西；末帧与第 0 帧完全一致，无丝巾、无光丝残留。
```
