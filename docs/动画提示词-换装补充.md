# 换装动作提示词（补充 10 条）

> **用法**：这份是 `原始素材\prompts.json` 的**增量**，与已交付的「整体换装试色」同系列的
> 变体（第一批配色：星夜 / 樱色 / 糖果；第二批配色：新年 / 冰雪 / 万圣 / 甜点；
> 第三批**全变装**（发型+发色+服装款式）：双马尾 / 丸子头 / 大小姐）。每条的五个字段（`name` / `slot` / `first_frame` / `last_frame` / `prompt`）
> 与现有 job 完全同构，直接粘进 `jobs[]` 即可；同名文件也已生成好：
> [`动画提示词-换装补充.jobs.json`](动画提示词-换装补充.jobs.json)（数组，转义已处理）。
> 生成参数沿用现有：`fps 24`、`canvas 1024×576`、首末帧锚图 `正面锚点-1024x576.png`。
>
> **与舞蹈篇的差异**：固定五段沿用 v3 绿幕规范（与舞蹈篇逐字同构），但动作里有
> "手持镜凭空凝聚 → 消散"与"换色光晕特效"，故 `【背景】`、`【首末帧硬约束】`、`【结尾重申】`
> 各含手持镜 / 特效例外句 —— 与舞蹈篇 `折扇舞` 的折扇例外是同一处理思路。
>
> **出片盯检点**：① 换色光晕掠过全身时抠像是否被打穿（角色内部出现半透明洞
> 就删掉特效词重刷）；② 两圈 360° 旋转后是否回正、配色是否彻底还原、镜子有无残留；
> ③ 全变装条目额外盯：呆毛 / 鳍耳是否保住、尾巴颜色是否跟上发色、脸型是否崩；
> 凭空凝聚比"从身后取出"对模型要求更高，若镜子出不来或消散不干净，
> 把"凭空变出"改成"从身后取出"、把"淡出消失"改成"递回身后"再重刷。
>
> **第 8~10 条是全变装**（发型 + 发色 + 服装款式都变）：因此 `【角色】` 段改为
> "同一角色、同一画风"并声明中途变化属于表演，`【首末帧硬约束】` 与 `【结尾重申】`
> 各多一句"末帧的发型、发色、服装与第 0 帧完全一致"。两条设定红线写进了提示词：
> **鲸鱼尾巴颜色随发色同步变化**（两者始终同色，否则穿帮）；**呆毛、鳍耳、尾巴形态
> 全程不变**（物种辨识特征）。
>
> 槽位统一 `小动作`（与舞蹈篇同池）。十条都不带文字、镜像后语义正常，**不需要** `noMirror`。
> 运行时换装类进「小动作」分类（与 整体换装试色 同池）；其中 `新年换装` 是节日款，
> 若以后想做节日专题，也可挂进目前空着的「时节」分类（注意空分类会白占权重，挂上才写）。
> 命名与已交付清单无冲突（已比对 `assets\config.jsonc`；「整体换装试色」是既有条目，本篇为新增）。
> ⚠ 配色红线：**不做绿色系**——绿幕抠像下绿衣服会被一起抠掉（负面词里本就禁"绿色衣服"）。

## 1. 星夜换装

```prompt
【背景（最高优先级，全程不可违背）】
纯绿幕抠像背景：背景是一整块均匀、平面、无光照的 #00FF00 绿幕布。整面背景从第 0 帧到最后一帧亮度与色值完全恒定：没有任何灯光把背景打亮或压暗，没有渐变，没有阴影，没有投影，没有光斑，没有景深，没有任何装饰。画面中永远只有这一个角色站在纯绿幕布正前方；本动作唯一允许的额外元素是角色手中的一面手持镜，此外空无一物。纯绿幕布从角色身后一直铺到画面底边；角色站立、起跳、悬空的正下方始终是这块纯绿幕布，脚与幕布接触处颜色与四周完全一致。

【角色】
Q 版蓝发鲸鱼女仆，与首帧锚图完全一致：同一角色、同一服装、同一发型、同一画风、同一大小，角色受光均匀恒定。

【首末帧硬约束】
第 0 帧与末帧由外部锚图锁定，均为标准正面站立：双脚并拢、双手自然垂于身体两侧、表情平和、目光平视前方，画面中无手持镜。
- 角色不放大、不缩小、不平移，双脚落点始终固定在画面水平正中。
- 手持镜由角色身前凭空凝聚出现，结束前完全消散，末帧无任何残留。
- 最后 1 秒内彻底回到标准站姿与干净纯绿画面，换色光晕特效完全消失。
- 第 1 秒之前完全静止。

【位置与安全区】
角色身高恒定为画幅高度的 75%，脚底距底边 8.3%，水平居中。全程任何部位（含呆毛、鳍耳、裙摆、鲸鱼尾巴、指尖）都在画幅内，与四边保持至少 8% 的纯绿间距。原地旋转与照镜全程，身体与手持镜不超出画幅安全区。

【构图与镜头】
固定机位，镜头完全不动，全身入镜。只表演下面描述的一个动作，不加戏。

【动作】
0~2秒（闭眼祈愿）：标准正面站立。双手在胸前合十，眼睛轻轻闭上，嘴角带着期待的笑意，身体微微左右摇晃（许愿般的蓄力感），随后双手向两侧柔柔挥出，指尖带起柔和的银色光点。
2~4秒（星夜换装）：身体原地轻快旋转一圈（360°）。旋转过程中，全身服装从原本配色整体平滑过渡为深邃的星夜蓝紫色系（裙子、围裙、荷叶边、蝴蝶结、发饰、手套、鞋子、领结等所有衣物元素同步变色，蝴蝶结与围裙边缘浮现细小的银色星光纹样，此为角色自身服装变化，背景保持纯绿不变），柔和的星辉光晕掠过全身。旋转结束定格时，全身女仆装已变为统一的星夜风格。女仆低头打量自己的新造型，眼睛睁大，表情惊喜，双手轻轻拉起裙摆左右看看。
4~6秒（照镜惊艳→陶醉）：手里凭空变出一面手持镜，举到面前端详整体效果。左转转、右转转，头部微侧，从各个角度欣赏自己的星夜新装。表情从惊喜逐渐变为陶醉（眼睛亮晶晶，嘴角上扬，轻轻点头），随后恋恋不舍地将镜子放下。
6~8秒（决定换回）：镜子在手中淡出消失，双手再次合十，表情转为温柔而坚定。身体再次原地轻快旋转一圈（360°）。旋转过程中，全身服装从星夜蓝紫色系平滑过渡回原本配色（所有衣物元素同步恢复，星光纹样隐去），柔和的星辉光晕再次掠过全身。
8~10秒（安心恢复）：旋转结束定格，全身服装已恢复原本配色。女仆低头确认，表情转为安心的微笑，轻轻点头。双手轻轻抚平裙摆，身体回正，表情恢复温和宁静。第10秒结束时彻底恢复为标准正面站立，全身服装配色与第 0 帧完全一致。

【结尾重申】
全程纯绿背景 #00FF00，除角色与一面手持镜外画面中不出现任何东西；末帧与第 0 帧完全一致，无手持镜残留。
```
